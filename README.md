# וואטסאפ למספר לא שמור 💬

כלי קטן שפותח צ'אט וואטסאפ **למספר שלא שמור באנשי הקשר** — בלי לשמור אותו.
מזינים מספר, לוחצים "פתח צ'אט", ונפתח `https://wa.me/<מספר בינלאומי>`.

**הכל רץ מקומית בדפדפן. שום מספר לא נשלח לשום מקום.**

## מה הוא יודע לעשות

- **מקבל כל פורמט** — `050-123-4567`, `+972 50 123 4567`, `00972501234567`,
  `03-1234567`, וגם מספרים בינלאומיים כמו `+44 7911 123456`.
- **מנרמל חכם** — למשל `+972-050-123-4567` הופך ל-`972501234567` (ולא
  ל-`9720501234567` השבור).
- **ולידציה קפדנית** — מספר ישראלי חייב להיות נייד (`05X-XXXXXXX`, 10 ספרות),
  `07X` או קווי (`0X-XXXXXXX`); גם אחרי `972` נדרשות 9 ספרות (נייד) או 8 (קווי).
  מספר זר מתקבל רק עם `+` או `00` מפורשים ובאורך E.164 (8 עד 15 ספרות).
  קלט לא תקין מציג הודעה ברורה וכפתור "פתח צ'אט" לא נפתח.
- **מציג בפורמט מקומי** כשהמספר הישראלי שלם — `050-123-4567` / `03-123-4567`
  (בלי קפיצות בזמן ההקלדה).
- **הודעה מוכנה מראש** (אופציונלי) שנכנסת לצ'אט מוכנה לשליחה.
- **אחרונים במכשיר זה** — עד 6 מספרים ב-`localStorage`, עם כפתור ניקוי.
- **עובד אופליין** כ-PWA, בלי CDN ובלי שום תלות חיצונית.

## התקנה כאפליקציה (PWA)

**אנדרואיד / כרום:** פותחים את האתר → תפריט ⋮ → *התקן אפליקציה* / *הוסף למסך הבית*.

**אייפון / ספארי:** פותחים את האתר → כפתור השיתוף ⬆️ → *הוספה למסך הבית*.

**מחשב (Chrome / Edge):** אייקון ההתקנה בשורת הכתובת → *התקן*.

אחרי ההתקנה הכלי נפתח כאפליקציה עצמאית ועובד גם בלי אינטרנט
(פתיחת הצ'אט עצמה כמובן דורשת רשת).

## הרצה מקומית

הקובץ עובד גם בפתיחה ישירה מהדיסק, אבל ה-service worker נרשם רק מעל
`http`/`https`:

```bash
python3 -m http.server 8000
# ואז: http://localhost:8000
```

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `index.html` | כל הכלי — HTML, CSS ו-JS בקובץ אחד |
| `manifest.json` | הגדרות ה-PWA |
| `sw.js` | service worker, cache-first |
| `make_icons.py` | סקריפט Pillow שמייצר את האייקונים |
| `icon-*.png`, `apple-touch-icon.png` | האייקונים |

יצירה מחדש של האייקונים:

```bash
pip install Pillow && python3 make_icons.py
```
